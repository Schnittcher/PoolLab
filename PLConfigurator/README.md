# PLConfigurator
Listet alle Pools (Accounts) des Cloud-Kontos auf und legt für jeden Pool die Instanzen Messwerte, Dosierungsempfehlung und Aktives Chlor samt Account-Splitter an. Der Konfigurator verbindet sich mit dem Cloud-Gateway, das beim Anlegen miterzeugt wird.

## 1. Konfiguration
Der Konfigurator hat keine eigenen Einstellungen. Der API-Token wird im Gateway (PLCloud) hinterlegt. In der Liste stehen je Pool Name, Ort und Wassermenge; darunter lassen sich die Instanzen anlegen.

## 2. Variablen
Der Konfigurator legt keine Variablen an.

## 3. Funktionen
Der Konfigurator hat keine öffentlichen Funktionen.
